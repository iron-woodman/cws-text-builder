1. Ключи (до написания)

ПравилоНормаПроверка
Квота ключей из Semrush: Main = ключ из названия + его хвосты, Extra = дополнительные15 + 15вручную
Extra — аналоги главного ключа: той же ширины или уже, не шире. Широкие (clear chat history) весят меньшене шире▲ если в Extra нет слов главного ключа
Релевантность: вбейте ключ в Google — выдача должна быть похожа на ваш продукт—вручную
Хвосты с названием ищите через Phrase Match и Exact Match, не только Broad Match—вручную
Убрать: перестановки, которые никто не вводит; ключи других платформ (… firefox); функции, которых нет; хвост названия в Extra → перенести в Main—вручную

2. Общие правила (название, короткое, полное)

ПравилоНормаПроверка
Запрещённые слова — модерация отклоняет: best free premium recommended #10✕

3. Короткое описание

ПравилоНормаПроверка
Длина≤ 132✕
Главный ключ (из названия) ровно 1 раз и не первым словом: Fast chatgpt bulk delete: …1✕
Ключей всего, включая главный. Частичные совпадения засчитываются (mass delete chats ← mass delete chatgpt chats). Приложение считает частичным фрагмент, где слова ключа идут подряд и выброшено ровно одно (минимум 2 слова; chat/chats — одно слово). Только для короткого: в полном ключи пишутся целиком3–6▲
Главное слово названия (delete). Разные формы одного корня (delete, deleting, deleted) даже лучше трёх одинаковых3, не больше✕ если >3
Любое другое слово (кроме служебных)≤ 2✕
Без воды, читабельно. Вопросные ключи оставьте для полного описания—вручную

5. Плотность (переспам)

ПравилоНормаПроверка
Плотность любого значимого слова по название + короткое + полное (как textchecker.online). Служебные слова не считаются< 3%✕
Исключение: слово из названия выше 3% на 1–2 вхождения — допустимо+1–2▲
Снижать спам удалением вхождений, а не удлинением текста: сначала не-ключевые упоминания, потом дубли ключей, потом ключи с объёмом 20—вручную
Финальная проверка: весь листинг одним текстом на textchecker.online — нет красных слов—вручную
Конфликт правил: если все ключи содержат слово названия (chatgpt), норма Extra 15–20 упирается в плотность 3%. Приоритет — плотность; Extra можно оставить ниже нормы, но ключ с наибольшим объёмом поставить в сильное место (заголовок или первые абзацы).

6. Как считает приложение

  • Times used — совпадения ключа без учёта регистра, целыми словами, по всему листингу; во всплывающей подсказке разбивка по полям. Ключ внутри длинного ключа засчитывается обоим (chatgpt bulk delete в chatgpt bulk delete extension).
  • Нормы 15–20 и 8–10 сверяются по полному описанию.
  • Плотность: слова [a-z0-9'], грубая лемма (chats → chat), процент от слов без чистых чисел — как textchecker.online.
  • Ключи подряд: между двумя ключами только пробел, запятая, ;, &, and или or. Вложенный ключ за пару не считается.
  • Ключи в абзаце: считаются все ключи Main и Extra, вложенные — как один; блоки-списки не проверяются.

7. Порядок работы

  1. Отобрать ключи (раздел 1), загрузить в Main и Extra.
  2. Написать короткое — 2 варианта, выбрать тот, что покрывает больше объёма ключей.
  3. Написать полное по скелету; добиться ✓ по ключам, структуре, длине.
  4. Снизить плотность до < 3% удалением вхождений.
  5. Один финальный прогон на textchecker.online, затем «Копировать для Google Docs» или «Сохранить .md».
